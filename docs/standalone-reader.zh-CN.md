# 独立 HTML 阅读

2.10 支持在浏览器中直接读取 v3 紧凑阅览版, 无需安装或运行 Storloom, 无需本机服务, 无需联网. 消息, 媒体和搜索索引仍保存在原归档中. HTML 是阅读入口, 单独复制它不包含聊天内容.

## 使用

在账号的阅览版配置页展开任务说明, 勾选 `启用独立 HTML 阅读`. 已有紧凑阅览版可在账号页点击 `独立 HTML 阅读`, 首次准备完成后会打开归档内的 `index.html`. 移动归档时保留整个目录.

用桌面浏览器打开 `index.html`, 点击 `选择归档目录`, 选择整个归档目录. 2.11 新建的阅览版将内部数据收进 `archive-data`, 根目录保留 HTML 入口; 也可直接选择数据子目录. 旧版平铺目录继续支持. 移动时请保留整个归档目录. 浏览器要求用户手势授予只读访问. 页面不能在首次打开时自动获得旁边文件的访问权限. 不支持目录句柄的浏览器可尝试 `兼容目录选择`, 此路径先枚举文件, 大目录会更慢. 取消目录选择可重试.

密码保护与直接密钥模式均沿用归档现有凭据. 密码保护仍支持快速修改密码, 无需重新加密消息或重新生成 HTML. 密码和解密后的消息不保存到浏览器数据库. 外观与阅读偏好继续使用本地设置; 存储不可用时只在本次打开期间有效.

勾选“记住此归档目录”后, 支持的浏览器只在 IndexedDB 保存目录句柄和归档标识. 下次打开时, 已有只读授权仍有效就恢复目录; 加密归档仍需输入密码或直接密钥. 授权失效时点击“继续打开”重新授权, 页面启动不会主动弹出授权窗口. “忘记目录”移除记录, 取消勾选也会移除记录, 并在本地存储可用时记住不保留目录的选择. 各 HTML 入口位置独立记录, 同一归档的不同副本也互不覆盖. 锁定后不会立即自动重开. 目录中归档被替换时要求重新明确选择. 浏览器策略、隐私模式、清除存储及本地文件 URL 限制可能导致记忆不可用, 此时仍可正常选择目录或使用兼容选择; 兼容文件列表不能记住.

2.12 起新建的紧凑归档将数据包放在 `archive-data/packs/`, 历史提交记录放在 `archive-data/commits/`, 查询索引和浏览器快照分别保留在 `query/`、`browser/`. 少量归档说明、密钥封装、当前快照及任务锁文件留在数据根目录, 作为控制信息. 新版兼容分类目录和旧版平铺目录; 旧版阅读器需更新后才能读取分类目录. 关闭阅览窗口后, 现有归档可通过同盘移动整理, 核对文件标识并保留已发布快照, 中断后的混合目录可以继续整理. exFAT 等文件系统移动后可能改变文件标识, 此时改用内容哈希校验, 会增加一次性读取开销. 分类不会重新加密内容, 也不会将消息拆成更多文件.

页面复用桌面阅读界面, 包括会话, 分页, 搜索, 引用定位, 身份资料和图片预览. 图片与小媒体按需读取. 超过 32 MiB 的单个媒体不会全部加载进页面内存, 显示保存入口. 支持文件保存 API 的浏览器会逐块保存, 其他浏览器的兼容下载只支持有上限的小文件. 保存该文件后可用外部播放器查看. 编解码器支持仍由浏览器决定.

点击 `锁定 / 关闭归档` 会终止读取 Worker, 释放页面与对象 URL, 再次打开需要重新选择并解锁. JavaScript 运行时不能保证物理擦除所有秘密副本. 页面 CSP 禁止网络连接及远程媒体, 归档脚本作为数据解析, 不执行归档内的脚本.

## 增量, 空间和速度

直接复用归档已有的查询数据库和媒体包. 只读 VFS 用 File.slice 与 Worker 中的 FileReaderSync 按需读取, 不把整份索引加载到内存, 不复制到 OPFS, 不重建另一套搜索倒排. 浏览器页缓存和对象 URL 缓存都有上限. 少量运行组件集中嵌入一个 HTML, 会话摘要放在现有查询库中, 另有很小的受保护快照目录.

首次为旧归档启用时需要按会话统计, 会读取索引, 日志显示准备阶段. 新归档从第一次提交起增量维护会话摘要, 后续启用 HTML 阅读时无需再扫描所有消息做会话统计. 原件备份需先解析为紧凑阅览版, 无法直接显示未解析的客户端数据库.

桌面阅读器将归档资源读取、搜索和文件保存移到后台, 串行访问查询连接, 图片延迟加载, 小资源响应缓存上限为 16 MiB. 媒体按每段最多 4 MiB 返回, 避免归档流在界面线程上继续读取慢盘. 这些措施改善界面响应, 不代表能消除磁盘吞吐限制. QQ 可通过可选的腾讯头像下载设置补齐联系人和群头像; 微信从支持的本地头像数据库读取. 不可用的头像保留占位, 补充头像不会替换历史身份记录.

入口绑定已发布 HEAD 和归档内部的查询快照. 正常后续更新会自动维护入口, 不重新解析全部消息来生成 HTML. 候选快照先准备, 归档 HEAD 最后发布; 中断后仍可读取已有快照. 浏览器发现归档变化时提示刷新. 兼容文件选择捕获的文件可能已失效, 此时需要重新选择目录. 归档更新时不要把它当成可持续无限期使用的旧查询文件副本.

归档复制会携带可用的独立阅读快照和索引, 整理及保护转换会为新副本生成对应入口. 如果旧副本缺少匹配快照或索引, 程序会提示重新生成入口, 不在浏览器中静默扫描全部历史数据包.

## 已验证范围

在本机独立 Edge 的 file:// 页面验证了明文, 密码与直接密钥归档, 错误凭据重试, 分页, 搜索, 引用, 图片, 大媒体限制, 锁定及快照变化. 未要求浏览器安全开关或额外启动参数. Chrome 使用相同能力路径, 本次没有可用的本机 Chrome 进行实测. 其他浏览器不作兼容保证. 目录授权受浏览器策略影响, 不可用时可使用明确标注的兼容选择.

查询耗时取决于索引大小, 磁盘和搜索词. 高频词或靠后页面可能需要更多索引访问, 单次查询有时间上限并显示失败提示, 不能将小样本的首屏速度等同于数百万条归档的所有操作速度.

解锁页与阅览内容共用配色选择, 在同一浏览器的阅览归档间通用. 修改亮暗和风格后, 锁定回到解锁页也会保持一致; 外观配置不包含密码或聊天内容. 页数和导航配置仍按归档分别保存.

内置阅览器打开现有归档时会复用匹配当前快照且通过认证的浏览器元数据, 减少重新访问数据包. 有会话汇总时, 分页从索引较近的一端读取. HTML 阅览器在输入密码阶段准备读取组件, 使用有容量上限的 16 KiB 索引预读, 合并同一头像或资源的同时请求. 现有归档格式保持兼容, 更新独立 HTML 入口即可获得浏览器侧优化. 磁盘寻道与大型搜索仍可能成为瓶颈.

归档中存在被引用原消息时, 引用展示其发送者与时间; 微信引用自带的时间也会保留. 只对可见引用按需查询元数据, 不逐条计算消息排名或加载整个会话. 跳转查找覆盖归档索引, QQ 在同一会话内兼容消息 ID 与序号的回退. 查询失败与未找到原消息分别提示; 未找到仅表示当前归档未收录或无法匹配, 不能据此判定客户端已删除消息. 搜索筛选面板收起后, 标题仍标明已启用条件并提供清除入口, 查询过程中另有忙碌提示. 每页条数输入与 SVG 预设按钮共用焦点外框.

QQ 引用恢复会读取原始内容自带的序号、发送者及时间, 兼容旧阅览版中已解析字段为空的消息. 跳转前按引用记录的发送者、时间核对候选序号, 不一致时明确提示, 避免定位到无关消息. 未记录的发送者或时间直接省略. 现有归档更新阅览入口即可生效, 无需重写聊天消息.
