# 独立 HTML 阅读

2.10 支持在浏览器中直接读取 v3 紧凑阅览版, 无需安装或运行 Storloom, 无需本机服务, 无需联网. 消息, 媒体和搜索索引仍保存在原归档中. HTML 是阅读入口, 单独复制它不包含聊天内容.

## 使用

在账号的阅览版配置页展开任务说明, 勾选 `启用独立 HTML 阅读`. 已有紧凑阅览版可在账号页点击 `独立 HTML 阅读`, 首次准备完成后会打开归档内的 `阅读.html`. 移动归档时保留整个目录.

用桌面浏览器打开 `阅读.html`, 点击 `选择归档目录`, 选择包含 archive.json 的目录. 浏览器要求用户手势授予只读访问. 页面不能在首次打开时自动获得旁边文件的访问权限. 不支持目录句柄的浏览器可尝试 `兼容目录选择`, 此路径先枚举文件, 大目录会更慢. 取消目录选择可重试.

密码保护与直接密钥模式均沿用归档现有凭据. 密码保护仍支持快速修改密码, 无需重新加密消息或重新生成 HTML. 密码和解密后的消息不保存到浏览器数据库. 外观与阅读偏好继续使用本地设置; 存储不可用时只在本次打开期间有效.

页面复用桌面阅读界面, 包括会话, 分页, 搜索, 引用定位, 身份资料和图片预览. 图片与小媒体按需读取. 超过 32 MiB 的单个媒体不会全部加载进页面内存, 显示保存入口. 支持文件保存 API 的浏览器会逐块保存, 其他浏览器的兼容下载只支持有上限的小文件. 保存该文件后可用外部播放器查看. 编解码器支持仍由浏览器决定.

点击 `锁定 / 关闭归档` 会终止读取 Worker, 释放页面与对象 URL, 再次打开需要重新选择并解锁. JavaScript 运行时不能保证物理擦除所有秘密副本. 页面 CSP 禁止网络连接及远程媒体, 归档脚本作为数据解析, 不执行归档内的脚本.

## 增量, 空间和速度

直接复用归档已有的查询数据库和媒体包. 只读 VFS 用 File.slice 与 Worker 中的 FileReaderSync 按需读取, 不把整份索引加载到内存, 不复制到 OPFS, 不重建另一套搜索倒排. 浏览器页缓存和对象 URL 缓存都有上限. 少量运行组件集中嵌入一个 HTML, 会话摘要放在现有查询库中, 另有很小的受保护快照目录.

首次为旧归档启用时需要按会话统计, 会读取索引, 日志显示准备阶段, 后续会话摘要随消息增量维护. 新建时选择启用会在发布前完成准备. 不启用的归档无需承担浏览器准备成本. 原件备份需先解析为紧凑阅览版, 无法直接显示未解析的客户端数据库.

入口绑定已发布 HEAD 和归档内部的查询快照. 正常后续更新会自动维护入口, 不重新解析全部消息来生成 HTML. 候选快照先准备, 归档 HEAD 最后发布; 中断后仍可读取已有快照. 浏览器发现归档变化时提示刷新. 兼容文件选择捕获的文件可能已失效, 此时需要重新选择目录. 归档更新时不要把它当成可持续无限期使用的旧查询文件副本.

归档复制会携带可用的独立阅读快照和索引, 整理及保护转换会为新副本生成对应入口. 如果旧副本缺少匹配快照或索引, 程序会提示重新生成入口, 不在浏览器中静默扫描全部历史数据包.

## 已验证范围

在本机独立 Edge 的 file:// 页面验证了明文, 密码与直接密钥归档, 错误凭据重试, 分页, 搜索, 引用, 图片, 大媒体限制, 锁定及快照变化. 未要求浏览器安全开关或额外启动参数. Chrome 使用相同能力路径, 本次没有可用的本机 Chrome 进行实测. 其他浏览器不作兼容保证. 目录授权受浏览器策略影响, 不可用时可使用明确标注的兼容选择.

查询耗时取决于索引大小, 磁盘和搜索词. 高频词或靠后页面可能需要更多索引访问, 单次查询有时间上限并显示失败提示, 不能将小样本的首屏速度等同于数百万条归档的所有操作速度.
