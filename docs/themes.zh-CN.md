# 主题与布局

Storloom的桌面界面采用WPF与WPF UI。主题资源统一管理应用标题栏、导航、控件、菜单、对话框、文字选区和滚动条。文件与文件夹选择器、UAC等系统窗口遵循Windows设置。

内置浅色主题使用白灰黑，深色(OneDark)使用深蓝灰配色。在“工具 -> 首选项”选择主题、减少动效或指定私有JSON主题文件。文件路径保存在本地首选项中，不应写入公开规则。清空路径即可使用内置配色。主题不会加载外部XAML或执行代码。

主题文件可以覆盖以下任意颜色，值必须使用六位十六进制格式`#RRGGBB`：

```json
{
  "Canvas": "#f6f6f6",
  "Surface": "#ffffff",
  "Sidebar": "#eeeeee",
  "Ink": "#242424",
  "Muted": "#5d5d5d",
  "Line": "#dddddd",
  "Accent": "#252525",
  "OnAccent": "#ffffff",
  "Selection": "#dddddd",
  "Hover": "#e8e8e8",
  "Danger": "#4b4b4b",
  "TextSelection": "#aaaaaa",
  "SelectedText": "#202020",
  "AccentText": "#252525",
  "ControlBorder": "#888888"
}
```

这些字段依次表示窗口背景、内容区、侧栏、正文、次要文字、边框、强调色、强调色上的文字、选中背景、悬停背景和危险状态。请保证前景与背景之间有足够对比度。未知字段和非法颜色会被拒绝。

主题通过动态资源更新。应用首选项会重建页面并作废当前清理扫描，执行前应重新扫描。

菜单与标题栏合为一行。按钮、输入框和下拉框统一采用32个逻辑像素的紧凑高度。侧栏分隔线外观为1个逻辑像素，可拖动区域扩大为10个逻辑像素。拖动侧栏或日志上方的分隔线可以调整尺寸，退出时保存在私有首选项中。手动滚动、按日志导航键或选择日志文字会暂停自动跟随。点击“跟随最新日志”或按Ctrl+Shift+L切换跟随；重新开启后回到最新行。追加日志不会抢走键盘焦点。仅在跟随时裁剪过长的实时日志，结构化操作记录另存于本地数据目录。

导航立即切换，菜单直接弹出。悬停和按下仅对背景色做65至100毫秒过渡，文字始终不透明且不缩放。进度与日志面板的过渡约为120至150毫秒。“减少动效”会关闭应用自行实现的过渡，阅读器也遵循系统的减少动态效果偏好。

多行及只读文本框不使用悬停、按下动效，编辑框获得焦点后保持背景稳定。侧栏可折叠为图标，宽度与折叠状态保存在私有首选项中。日志分隔条仅显示细线，周围保留拖拽区域；右侧箭头图标可展开或收起日志。

侧栏收展时保持图标纵向位置不变。日志分隔条受窗口可用高度限制，并为当前页面保留空间；长日志的横向、纵向滚动条分别布局。首选项中的关闭按钮设置可启用隐藏到托盘，隐藏期间任务继续执行；托盘菜单可恢复窗口或退出。任务运行时退出需要确认，并会等待任务取消完成。

确认和信息提示采用随内容调整高度的紧凑窗口，不提供最大化或拉伸；长说明在有高度限制的区域内滚动，操作按钮位于右下方。聊天备份与完成页为账号、原始备份和阅读版路径设置左侧标签，行间距保持一致。滚动条轨道与滑块使用一致的最小尺寸，长文档滚动到两端时不会再截断滑块。

内置配色将强调色填充、强调色文字和控件轮廓分开管理。文字前景与对应背景的对比度测试下限为 4.5，输入框轮廓相对底色的下限为 3。主按钮按下时，背景向远离文字颜色的方向变化，避免变亮后文字难读。阅读器验证聊天客户端 三套配色的浅色与深色组合，包含自己发送的气泡提示文字，以及使用独立底色的占位内容。自定义覆盖值仍由用户决定，这些内置测试不代表任意自定义主题都已通过验证。


内置主题顺序为：浅色、深色（灰度）、OneDark。纯色主按钮依靠填充色区分，不显示常态高亮边框；键盘导航时显示独立焦点提示。原来的 OneDark 设置仍然有效。
