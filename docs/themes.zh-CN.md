# 主题与布局

Storloom的桌面界面采用WPF与WPF UI。主题资源统一管理应用标题栏、导航、控件、菜单、对话框、文字选区和滚动条。文件与文件夹选择器、UAC等系统窗口遵循Windows设置。

内置浅色主题使用白灰黑，深色(OneDark)使用深蓝灰配色。在“工具 -> 首选项”选择主题、减少动效或指定私有JSON主题文件。文件路径保存在本地首选项中，不应写入公开规则。清空路径即可使用内置配色。主题不会加载外部XAML或执行代码。

主题文件可以覆盖以下任意颜色，值必须使用六位十六进制格式`#RRGGBB`：

```json
{
  "Canvas": "#f6f6f6",
  "Surface": "#ffffff",
  "Sidebar": "#eeeeee",
  "Ink": "#242424",
  "Muted": "#686868",
  "Line": "#dddddd",
  "Accent": "#252525",
  "OnAccent": "#ffffff",
  "Selection": "#dddddd",
  "Hover": "#e8e8e8",
  "Danger": "#4b4b4b"
}
```

这些字段依次表示窗口背景、内容区、侧栏、正文、次要文字、边框、强调色、强调色上的文字、选中背景、悬停背景和危险状态。请保证前景与背景之间有足够对比度。未知字段和非法颜色会被拒绝。

主题通过动态资源更新。应用首选项会重建页面并作废当前清理扫描，执行前应重新扫描。

菜单与标题栏合为一行。按钮、输入框和下拉框统一采用32个逻辑像素的紧凑高度。侧栏分隔线外观为1个逻辑像素，可拖动区域扩大为10个逻辑像素。拖动侧栏或日志上方的分隔线可以调整尺寸，退出时保存在私有首选项中。手动滚动、按日志导航键或选择日志文字会暂停自动跟随。点击“跟随最新日志”或按Ctrl+Shift+L切换跟随；重新开启后回到最新行。追加日志不会抢走键盘焦点。仅在跟随时裁剪过长的实时日志，结构化操作记录另存于本地数据目录。

导航立即切换，菜单直接弹出。悬停和按下仅对背景色做65至100毫秒过渡，文字始终不透明且不缩放。进度与日志面板的过渡约为120至150毫秒。“减少动效”会关闭应用自行实现的过渡，阅读器也遵循系统的减少动态效果偏好。
