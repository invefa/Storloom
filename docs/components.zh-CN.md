# 桌面组件库

从 **工具 → 组件库** 打开可交互的 WPF 展示窗口。展示使用与程序相同的真实组件，跟随全局主题，仅含示例数据，不会扫描或删除文件。

第一版组件库保留在桌面项目内部：`Desktop/CompactControls.xaml` 提供共用模板，`Desktop/View.cs` 提供布局与控件工厂，`Desktop/Components` 提供行为组件。业务页面组合这些组件，不再各自绘制选择标记或重复实现批量选择。

## 视觉规则

- 颜色使用 Canvas、Surface、Ink、Muted、Accent、OnAccent、Selection、Danger、ControlBorder 等主题资源，窗口不单独写死配色。
- 沿用紧凑控件、32 DIP 输入与操作高度，以及四的倍数间距。标签对齐，窄窗口允许操作换行、内容滚动。
- 复选框使用矢量图形：全不选为空框，全选为对号，部分选择为整块实心填充，不含内部白色方块。状态同时通过图形与颜色表达。
- 纯复选框表格列宽为 28 DIP，表头不保留文字内边距；16 DIP 图形位于居中的 20 DIP 控件内。没有标签时不预留标签间距。
- 键盘焦点始终可辨。图标按钮提供名称、提示和无障碍标识；不可用状态与可操作状态明确区分。

## 可复用行为

`TableSelection` 连接表格的复选框列。行实现 `ISelectableRow`，提供 `Selected` 和 `INotifyPropertyChanged`。组件监听行状态和视图变化，计算表头状态，并提供 `Set(true)`、`Set(false)` 和 `Invert()`。点击表头或按空格会在全选、全不选之间切换；部分选中时点击会全选。筛选后的全选、反选只作用于当前显示行，隐藏行的选择保留。替换数据源时解除旧行监听，批量操作完成后只发出一次选择通知。

清理页分别为规则和文件列表创建实例，组件展示窗口使用同一实现配合示例数据。扫描范围、文件排除列表和执行授权仍由业务逻辑管理，组件只负责界面选择。

`AdaptiveTable` 由 `View.Table` 统一创建。内容填充并显示后测量原生单元格与表头模板，同时等距抽样最多 256 行（包含末行），无需实例化这些行的界面。列宽占满视口，优先压缩最长列，保留短列与最小宽度；最小宽度总和仍放不下时允许横向滚动。拖动列宽或主动适配单列后进入手动模式，允许横向溢出，窗口缩放及重新进入同一视图都保留手动宽度。更换 ItemsSource 后恢复自动适配；“重置列宽”也恢复视口适配。抽样限制大扫描结果的打开开销；未被抽中的屏外极长内容仍可能截断，可通过悬浮提示或手动拉宽查看。

`StatusBanner` 通过 `Show(text, tone)` 提供信息、处理中、完成、错误状态。统一使用矢量图标、主题颜色和无障碍动态区域；只有处理中显示不定进度条。组件不执行业务操作、不切换页面、不清空输入。

`View.Button`、`View.IconButton`、`View.Input`、`View.SecretInput`、`View.Field`、`View.Table`、`View.Card` 和 `View.FormScroll` 仍为基础构件。优先复用这些工厂与 WPF 模板，有跨功能共用的行为时再添加组件，避免为每个页面重复封装。

## 验证

展示窗口包含操作入口、输入、三态选择、表格筛选与批量选择、加载、完成和校验反馈。界面测试覆盖亮色、暗色、OneDark 的状态切换、筛选、旧行解除监听和表头图形边界；截图仅使用示例数据。实际清理流程另行验证扫描范围、处理前确认，以及未勾选文件的保留。
