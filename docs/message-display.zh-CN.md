# 消息展示与导航

阅读版按顺序展示文字、行内提及及内置表情；独立图片和动画使用无气泡展示，图文混合仍保留气泡。语音使用紧凑播放器。同一图片的多个资源可在原始内容入口旁切换或全部展示。

支持的记录包括文件、引用回复、合并转发、链接、小程序、联系人、位置、通话、支付、礼物、系统通知、撤回及戳一戳。未知字段保留明确占位和原始数据；历史支付卡片不代表当前结算状态。

能获得的消息贴表情显示为对应消息下方的表情／数量标签，撤回另作系统通知。缺失的回应字段不能从截图或撤回事件推断。已过期或本地缺失的附件仍会提示不可用。

## 阅读导航

支持首页、尾页、指定页，以及当前页顶部／底部。每页可设置 100–2,000 条消息，更多消息会增加内存和渲染开销。此设置只影响展示，不改写归档数据。

搜索可组合内容、发送人、类别、日期及自己发送的消息，范围可选当前会话或整个已打开归档。Ctrl+Shift+F 打开归档搜索。结果进入消息上下文后保留返回位置。会话支持查找前后匹配页，归档搜索按有界批次展示。

引用仅跳转到准确匹配的归档消息，找不到时短暂提示，找到后高亮。点击头像或姓名可查看可用资料及观察到的曾用名／头像记录；点击会话标题打开详情。已归档发送人是历史观察，不代表当前完整群成员名单。

可选导航预览用轻量标记表示当前已加载页面，收起保留内容，关闭释放画布和观察器。它不额外加载聊天历史或媒体。侧栏宽度和图片预览大小在本地记忆。

## 媒体与原始内容

图片预览支持拖动、拉伸、滚轮缩放、旋转、复制、另存及定位到发送消息；头像共用相同预览器。浏览器中的复制能力受权限约束，主动复制或另存会产生明文。

原始内容默认折叠，在展开时才建立显示节点，宽度独立于气泡。已知二进制结构提供有界字段预览，不给未知字段猜测含义。普通阅读版可更新展示代码而不改写聊天正文；补资源或新解析内容可能仍需要匹配的原始备份和密钥。

## 展示边界

聊天客户端版本及资源布局会变化。本地加密图片、动画缓存、语音数据库、安装目录表情表，仅在识别且验证其结构时支持。缩略图回退会有标注，缺失媒体与未知消息分别计数。阅读版不能替代经过核验的原始备份，也不能保证恢复源目录中不存在或已过期的资源。
